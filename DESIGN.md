# Design

Public project page expands the existing charcoal and parchment palette into a NieR-inspired archive interface. Original geometric artwork, fine rules, square controls and generous negative space. No official art or affiliation claims.

- Surface #dedbd0; ink #35372f; secondary ink #626357.
- Display: self-hosted Marcellus (OFL); CJK system serif; system sans body.
- Composition: editorial title and download action beside a geometric local-system diagram. Numbered setup steps convey an actual sequence.
- Language selection updates explanatory copy, document language and title. Local persistence is optional.
- Mobile: stacked diagram and wrapping navigation, no horizontal scrolling.
- Semantic headings, visible focus, reduced motion, no continuous animation.
