Prepare the environment once. After that, start from a single file.

System
Windows / macOS / Linux
Python 3.10+
Chrome / Edge
Android
An ADB-enabled emulator or device with compatible ARM64 support. No vendor is required; new combinations are untested.
Game files
A patched global 3.7.1 APK, Android assets and patched Master Data. Not included.
Full preparation guide ↗
  1. 01

    Set up the launcher

    Extract the download and run the setup command for your system below. Python dependencies stay in the project folder.

    .\setup.cmd
  2. 02

    Connect your environment

    Edit config.json with your ADB path, emulator address and server directory. Then run these commands in the project folder.

    .\launch.cmd fetch-tools
.\launch.cmd init-db
  3. 03

    Add your game files

    Follow the full guide to install your patched APK and place the assets and Master Data. Run the check command below to inspect the setup.

    .\doctor.cmd
  4. 04

    Open your local window

    Run the start command below, then choose「連接畫面」(Connect screen) and「啟動遊戲」(Launch game). Stop with stop.cmd on Windows or sh stop.sh on macOS/Linux.

    .\start.cmd

A few things to know.

Do I have to use MuMu?

No. Use Android Studio AVD, a vendor emulator or another compatible Android device through ADB. Leave emulator_start empty to start it manually, or configure an argument array. serial accepts auto, emulator IDs, TCP and USB devices. ARM64 game compatibility, ADB reverse and scrcpy are required; these combinations are untested.

Can I play directly on this website?

This site provides downloads and instructions. The game runs on your PC's Android emulator; a local browser page displays and controls it. No cloud game service is provided.

Does changing the language translate the game?

The language selector changes this website only. Game text depends on the client and assets. Traditional Chinese gameplay has not been verified, and no translation patch is included.
