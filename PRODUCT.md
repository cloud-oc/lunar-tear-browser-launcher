# Product
<!-- impeccable:product-schema 1 -->

## Platform
web

## Users and purpose
Players setting up Lunar Tear locally on Windows, macOS and Linux. The public website explains prerequisites and directs readers to download the launcher and follow a short guide. It does not run the game.

## Capabilities and constraints
Python launcher, local Android emulator, ADB, Lunar Tear and scrcpy. Cross-platform host code and vendor-neutral ADB transport are implemented. Earlier MuMu Android 15 streaming was verified; the expanded platform/emulator combinations have not been tested. Game files must be supplied separately. Full gameplay and Chinese game text are not verified. GitHub Pages hosts static project information only.

## Brand commitments
User-requested NieR-inspired design. Unofficial project; no official game art provided. Multilingual onboarding requested. English, Simplified Chinese, Traditional Chinese and Japanese are the initial editorial selection.

## Evidence
Existing README, config.example.json, launcher.py, browser.html; local tests and browser-stream verification. No full-playthrough evidence.
